# Customer Churn Prediction Using IBM SPSS Modeler

## Introduction
This project focuses on customer churn prediction using IBM SPSS Modeler. Customer churn refers to customers discontinuing the use of a company's products or services.

## Objective
The objective is to work with telecommunications customer data and develop a workflow related to churn modelling and customer risk analysis.

## Software Used
- IBM SPSS Modeler
- Microsoft Excel

## Project Workflow
1. Import Telco customer modelling data.
2. Inspect and prepare the data.
3. Define data types and use the churn-related modelling nodes.
4. View the outputs using Table nodes.
5. Work with deployment data.
6. Use the customer risk workflow for further analysis.

## Project Files
- IBM SPSS Modeler stream file (.str)
- Customer modelling dataset
- Deployment dataset (if available)
- Project introduction and workflow documentation
- Practical screenshots and available outputs

## Conclusion
This practical demonstrates the use of IBM SPSS Modeler for customer churn-related analysis. It provides an organised workflow for working with customer data, modelling churn and examining customer risk.
